# 工作人員使用指南

1. **登入**：使用業主邀請信設定密碼；忘記密碼按「寄送重設密碼信」。
2. **預約詢問**：底部「預約 → 新增詢問」，選飼主、貓咪、日期與房型。伺服器重新驗價並保存報價版本；詢問中不占實體房。清單依入住日升冪，可搜尋與分開查看即將入住／歷史。
3. **付款證明**：預約明細可上傳 1–8 張截圖；上傳只進入待核對，不會自動確認付款。只有業主核對實際金額後才入帳。
4. **房間**：預設為固定 21 房實體配置，可切換列表與週／月房況月曆。手機可用「符合畫面」、縮放及包含式橫向捲動；顯示設定只影響本人畫面。
5. **入住**：確認預約/飼主/貓咪/房間/實際時間，逐一登記行李、食物、保健品、藥品與照片；未確認指示保持草稿。確認 care plan 後才產生工作。
6. **物品**：資料綁定這一次住宿；共用品標成 shared，登記原始/剩餘數量、位置、效期、用法與是否歸還。取出餵食時記「已取出／提供」，觀察到吃多少再記「已食用」；後者不會重複扣庫存。未知數量須先人工盤點初始化。
7. **每日照護**：每隻貓、每一天獨立填餐點、飲水、排尿、排便與活動。同房摘要只有全部適用項目完成才完成；無法辨識的共用貓砂盆觀察記在房間層級，不歸到任何單一貓咪。
8. **用藥**：先核對已確認的獸醫/飼主指示，claim 後執行；不得自行推算或改劑量。不成功/不確定選對應狀態，系統會產生追蹤工作。
9. **異常**：選類別、嚴重度、時間、說明、照片與追蹤人。疑似無法排尿或呼吸困難立即聯絡主管與獸醫，不等例行報告。
10. **交接**：檢查未完成餐點、觀察、用藥、異常、低庫存、通知、入住/退房與清潔；重要交接須接班人確認，不會自動完成。
11. **明日通知**：待辦顯示入住/退房 LINE 文案。按「複製」不代表已送出；實際傳送後再標記已送出並記錄回覆。
12. **飼主日報**：只使用實際紀錄，預覽並人工核准後才複製/發布；不要加入內部備註、處方或其他客戶資料。
13. **退房**：核對照護/異常/尾款與每件行李，記錄歸還狀態、例外理由與照片；完成後產生清潔工作。
14. **清潔**：貓砂盆、食盆/水盆、寢具與消毒全部完成後，房間才回到可入住。
15. **搜尋歷史**：預約頁可依貓咪、飼主、房間、編號搜尋；完整日期/類型歷史 UI 尚在後續里程碑。

目前完整可操作 UI 為登入、首頁、三種房況視圖、預約詢問與報價版本、付款證明、飼主/貓咪新增與搜尋、21 房核對、入住草稿/完成、多貓照護摘要、五類每日照護、住宿物品、異常回報、用藥安全流程、飼主日報、退房物品核對、清潔完成、排班/交接、明日通知與待辦檢視。其他待完成項目以 `TASKS.md` 為準。
