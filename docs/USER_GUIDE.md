# 工作人員使用指南

1. **登入**：使用業主邀請信設定密碼；忘記密碼按「寄送重設密碼信」。
2. **預約**：底部「預約 → 新增」，選飼主、貓咪、日期與實際房間。畫面顯示夜數、方案、訂金與尾款；建立時伺服器會重新驗價並檢查房間重疊。
3. **入住**：確認預約/飼主/貓咪/房間/實際時間，逐一登記行李、食物、保健品、藥品與照片；未確認指示保持草稿。確認 care plan 後才產生工作。
4. **物品**：資料綁定這一次住宿；共用品標成 shared，登記原始/剩餘數量、位置、效期、用法與是否歸還。
5. **每日照護**：每隻貓、每一天獨立填餐點、飲水、排尿、排便與活動。提供食物不代表已吃完；未觀察與未排泄分開選。
6. **用藥**：先核對已確認的獸醫/飼主指示，claim 後執行；不得自行推算或改劑量。不成功/不確定選對應狀態，系統會產生追蹤工作。
7. **異常**：選類別、嚴重度、時間、說明、照片與追蹤人。疑似無法排尿或呼吸困難立即聯絡主管與獸醫，不等例行報告。
8. **交接**：檢查未完成餐點、觀察、用藥、異常、低庫存、通知、入住/退房與清潔；重要交接須接班人確認，不會自動完成。
9. **明日通知**：待辦顯示入住/退房 LINE 文案。按「複製」不代表已送出；實際傳送後再標記已送出並記錄回覆。
10. **飼主日報**：只使用實際紀錄，預覽並人工核准後才複製/發布；不要加入內部備註、處方或其他客戶資料。
11. **退房**：核對照護/異常/尾款與每件行李，記錄歸還狀態、例外理由與照片；完成後產生清潔工作。
12. **清潔**：貓砂盆、食盆/水盆、寢具與消毒全部完成後，房間才回到可入住。
13. **搜尋歷史**：預約頁可依貓咪、飼主、房間、編號搜尋；完整日期/類型歷史 UI 尚在後續里程碑。

目前完整可操作 UI 為登入、首頁、房況、飼主/貓咪新增與搜尋、業主新增實體房間、雲端預約與待辦檢視；其他專用操作 UI 尚未完成，資料庫結構已準備。以 `TASKS.md` 為準，勿把功能入口說明視為已上線。
